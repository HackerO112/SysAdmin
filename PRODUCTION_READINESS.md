# Repository quality assessment

Status: **curated resource directory, not a deployable software product**.

The repository currently consists of a README-style directory of third-party developer, Android, privacy, and learning resources. Production quality here means reliable curation rather than application infrastructure.

## Quality gates
1. Add a short purpose and audience statement for each resource.
2. Record source, last-verified date, pricing/availability caveats, and safety/legal notes where relevant.
3. Review external links periodically and remove dead, misleading, or unsafe destinations.
4. Clearly distinguish official project links from mirrors and community builds.
5. Do not imply endorsement or guarantee the safety of third-party tools.

CI checks relative Markdown links only; it cannot certify external resources.
